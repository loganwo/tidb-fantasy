# 分片城邦：TiDB 幻境

> **守城策略游戏 × TiDB 原理教学** —— 十万大军压境，你是城邦的调度官。

## 一句话玩法

敌军轮番攻城，你要在 4~6 座城区之间**调配战争物资**守住城池：种经济、造防线、拖仓支援、御敌反击——一边打游戏，一边自然理解 TiDB 的分片、副本、调度与容灾。

## 新手三步走

1. **开局先种经济**：选 ☀ 能量节点（50⚡）放在最左列，种 2~3 个——能量是一切的根基；
2. **敌军来袭前布防线**：🏹 副本兵（100⚡）负责输出，🛡 Raft 堡垒（75⚡）顶在前面挡刀；
3. **敌军攻城时**：往被围的城**拖仓支援**（仓是城墙的血条），或攒 3⚡ 点【御敌反击】出城冲杀。

> 口诀：**蓝点流、黄点挤、红点冒 → 按分裂。有 20💰 才按，红堆消失就停手攒钱。**（塔防模式适用）

## 核心规则

| 系统 | 规则 | 对应 TiDB 原理 |
|---|---|---|
| 数据轨道 | 查询是发光洪流，节点处理力有限 | TiKV 处理查询 |
| 堆积变红 | 查询堆积=热点，持续积累风险 | 负载倾斜 / 热点 Region |
| 分裂轨道 | 一分为二、处理力翻倍（20💰） | Region Split |
| 三仓存续 | 每批物资 3 仓分守 3 城，绝不同城 | Raft 三副本 |
| 烧到只剩 1 仓 | 濒危警告，再被烧一次彻底灭失 | 多数派告急 |
| 烧光 3 仓 | 永久灭失（不可恢复） | 数据丢失 |
| 敌军攻城 | 两阶段：行军预警 → 围攻消耗战 | 故障注入 |
| 围攻消耗战 | 每 3 秒焚 1 仓，撑满 14 秒敌军撤 | 节点持续承压 |
| 空城即陷落 | 城里没仓=不战而下 | 无副本=无容灾 |
| 御敌反击 | 需城内 ≥3 仓当兵源，把敌军推退 45% | 有资源才敢打 |
| 新城奠基 | 围攻战中新城上线，扩容机会 | 在线扩容 scale-out |
| 弃城之令 | 一城有序撤空下线 | 有序缩容 |

## 关卡（10 关 · 4 章，全部紧凑节奏）

| 章 | 关卡 | 时长 | 特色 |
|---|---|---|---|
| 一 · 先锋试探 | 1 黑色倒计时 / 2 连环警报 | 35s / 45s | 首波 2s/4s 即至，学会守城 |
| 二 · 大军压境 | 3 贸易洪峰 / 4 断粮孤城 | 40s / 50s | 洪峰+攻城双线、断粮低算力 |
| 三 · 围城苦战 | 5 热点妖火 / 6 扩城屯兵 / 7 弃守之令 | 40~45s | 妖火、新城奠基、弃城撤守 |
| 四 · 十万大军总攻 | 8 混战之夜 / 9 三线告急 / 10 城邦之主 | 50~65s | 多门齐攻 1→2→3 递进，全灾难并发 |

**难度递进**：敌军首波 2s→4s→5s（越往后越拼手速）；同时攻城 1 门→2 门→3 门；总攻关算力削弱。

## 成长系统（跨关持久）

- **💰 金币**：处理查询、守住围攻、完成任务都赚金币——**短线**：战斗中 10💰=1⚡ 紧急充电；**长线**：军备商店买永久升级；
- **🛡 永久军备**：城墙加固（风险-15%/级×3）、箭塔（行军+2s/级×3）、急修队——**跨关继承，越买越强**；
- **🪨 城邦等级**：石料升级城邦，Lv2 商店 9 折 / Lv3 算力上限+1 / Lv4 围攻减速 / Lv5 御敌首免；
- **🎖 任务徽章**：每关 2~4 个任务（不丢城/转运 N 次/峰值风险≤40），全达成给徽章；
- **称号**：见习生 → 值守调度官 → 全局调度官 → 首席容灾官 → 城邦之主。

## 三条制胜心法

1. **经济先行**：前 20 秒种满能量节点，没能量一切都是空谈；
2. **仓是城墙的血条**：被围的城靠拖仓硬扛，空城会被直接占领——永远给每座城留仓；
3. **阵型即容灾**：堡垒护住副本兵、多数派相邻增伤——好阵型本身就是 Raft 架构。
